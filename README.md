# کیف پول شخصی

اپلیکیشن مدیریت دخل‌وخرج فارسی با PHP، SQLite، PWA، گزارش‌گیری، رسید تصویر و قابلیت‌های AI.

## انتشار امن در GitHub

این مخزن فقط برای **کد برنامه** است. فایل‌های خصوصی مانند دیتابیس، تراکنش‌ها، تصاویر فاکتور، لاگ‌ها و کلیدهای API توسط `.gitignore` منتشر نمی‌شوند.

> GitHub Pages برای این نسخه مناسب نیست؛ چون PHP، SQLite، ورود کاربران و آپلود فایل را اجرا نمی‌کند. پروژه را روی هاست دارای PHP اجرا کنید و GitHub را برای نگهداری کد به‌کار ببرید.

## نصب روی هاست PHP

1. فایل‌های مخزن را روی هاست آپلود کنید.
2. `config.example.php` را با نام `config.php` کپی کنید.
3. کلید AI و مدل دلخواه را در `config.php` وارد کنید.
4. برای پوشه‌های `data`، `uploads` و `backups` مجوز نوشتن تنظیم کنید (معمولاً 755 یا در صورت نیاز 775).
5. مطمئن شوید PHP 8.0+، افزونه‌های `pdo_sqlite`، `curl` و `fileinfo` فعال هستند.
6. سایت را با HTTPS اجرا کنید تا PWA، دوربین و نشست امن کار کنند.

## آماده‌سازی برای اولین انتشار

```bash
git init
git add .
git commit -m "Initial public source release"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

قبل از اجرای دستورها، مطمئن شوید فایل‌های خصوصی با `git status` نمایش داده نمی‌شوند. اگر قبلاً کلید API یا دیتابیس را commit کرده‌اید، کلید AI را فوراً تعویض کنید و تاریخچه Git را پاک‌سازی کنید.
