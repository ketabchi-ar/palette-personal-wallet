# Palette Personal Wallet

یک اپلیکیشن فارسی، راست‌چین و نصب‌پذیر برای مدیریت دخل‌وخرج شخصی. این پروژه با تمرکز بر استفاده روزمره طراحی شده است: ثبت سریع و دقیق تراکنش، گزارش ماهانه، مدیریت چند کیف‌پول، رسیدهای تصویری و دستیار مالی مبتنی بر هوش مصنوعی.

> این نسخه یک برنامه PHP + SQLite است و برای اجرا روی هاست PHP طراحی شده؛ GitHub Pages از PHP، پایگاه‌داده و ورود کاربران پشتیبانی نمی‌کند.

## چرا Palette Personal Wallet؟

- رابط فارسی و RTL با پشتیبانی کامل از تاریخ شمسی
- PWA نصب‌پذیر روی موبایل و دسکتاپ، با قابلیت استفاده آفلاین و همگام‌سازی بعدی
- حساب کاربری مستقل برای هر کاربر و پنل مدیریت
- ذخیره‌سازی ابری خودکار روی هاست، در کنار نگه‌داری موقت داده در مرورگر هنگام قطعی اینترنت
- طراحی واکنش‌گرا برای تلفن همراه و دسکتاپ

## امکانات اصلی

### مدیریت مالی روزانه

- ثبت، ویرایش و حذف تراکنش‌های درآمد و هزینه
- انتخاب تاریخ شمسی با انتخاب‌گر چرخشی روز، ماه و سال
- دسته‌بندی‌های پیش‌فرض و ساخت دسته‌بندی دلخواه
- چند کیف‌پول برای تفکیک حساب‌ها و منابع مالی
- ثبت و تسویه طلب و بدهی
- تراکنش‌های تکرارشونده برای قبوض، اقساط و پرداخت‌های ثابت
- هدف‌گذاری مالی و دنبال‌کردن روند پس‌انداز
- تعیین بودجه ماهانه و نمایش میزان مصرف آن

### جست‌وجو، گزارش و خروجی

- جست‌وجوی تراکنش بر اساس توضیح، مبلغ، دسته‌بندی یا تگ افراد مانند `@نام`
- فیلتر نوع تراکنش، کیف‌پول و بازه مبلغ
- گزارش درآمد، هزینه، تراز، روند ماهانه و مقایسه ماه جاری با ماه قبل/بعد
- خلاصه اختصاصی هنگام فیلتر تراکنش‌های یک شخص و خروجی PDF
- خروجی JSON برای پشتیبان‌گیری، CSV برای Excel و نسخه قابل چاپ/PDF
- تولید و اشتراک‌گذاری رسید تصویری برای هر تراکنش

### رسید و فاکتور

- انتخاب تصویر از گالری یا گرفتن مستقیم عکس با دوربین موبایل
- فشرده‌سازی تصویر قبل از آپلود، با حفظ نسبت تصویر
- برش مرکز تصویر در قاب مناسب فاکتور پیش از ذخیره
- نمایش تصویر فاکتور داخل رسید خروجی با قاب خوانا

### هوش مصنوعی

- گفت‌وگوی فارسی با دستیار مالی و نگه‌داری تاریخچه گفتگوها در مرورگر
- نام‌گذاری، ایجاد و حذف گفتگوها
- تحلیل هزینه‌ها، بودجه و بینش‌های مالی قابل اقدام
- پاسخ قطعی برای مقایسه دخل‌وخرج ماه‌های شمسی، مستقیم از تراکنش‌های SQLite
- پیشنهاد ثبت تراکنش از متن یا گفتار؛ کاربر پیش از ثبت نهایی اطلاعات را تأیید یا ویرایش می‌کند
- ورودی صوتی فارسی در چت و میانبر ثبت صوتی تراکنش
- خواندن فاکتور با AI/OCR برای مدل‌های دارای پشتیبانی تصویر
- پشتیبانی از سرویس‌های سازگار با OpenAI مانند OpenAI، OpenRouter، Google Gemini و آدرس سفارشی

### پنل مدیریت

- مشاهده آمار کلی، کاربران و وضعیت فعالیت آن‌ها
- فعال/غیرفعال‌سازی کاربر، حذف کاربر و بازنشانی رمز عبور
- تنظیمات مرکزی سرویس هوش مصنوعی و تست اتصال
- ارسال پیام همگانی به کاربران
- مشاهده لاگ‌های سیستم از پنل
- ایجاد، دانلود و بازگردانی پشتیبان SQLite با یک نسخه ایمن قبل از بازگردانی

## فناوری‌ها

- **Backend:** PHP 8+
- **Database:** SQLite با PDO
- **Frontend:** HTML، JavaScript و Bootstrap RTL
- **PWA:** Web App Manifest و Service Worker
- **AI:** API سازگار با OpenAI
- **Export:** JSON، CSV/Excel، Print/PDF و رسید PNG

## نصب روی هاست

### پیش‌نیازها

- PHP 8.0 یا جدیدتر
- افزونه‌های PHP: `pdo_sqlite`، `curl` و `fileinfo`
- فعال بودن HTTPS برای تجربه مناسب PWA، دوربین و نشست امن

### مراحل نصب

1. فایل‌های پروژه را روی هاست PHP آپلود کنید.
2. فایل `config.example.php` را کپی و نام نسخه جدید را `config.php` بگذارید.
3. در `config.php` تنظیمات AI دلخواه را وارد کنید یا این بخش را خالی بگذارید.
4. مطمئن شوید وب‌سرور اجازه نوشتن در این پوشه‌ها را دارد:

   ```text
   data/
   uploads/
   backups/
   ```

   معمولاً سطح دسترسی `755` کافی است؛ در برخی هاست‌ها ممکن است به `775` نیاز باشد.

5. دامنه را با HTTPS باز کنید و یک حساب جدید بسازید.

## تنظیم AI

برای چت، تحلیل و OCR باید یک API Key معتبر وارد کنید. از پنل برنامه به بخش **دستیار هوشمند ← تنظیمات** بروید و یکی از سرویس‌دهنده‌های آماده یا آدرس سفارشی را انتخاب کنید.

برای خواندن فاکتور، مدل انتخابی باید از ورودی تصویر (Vision / Multimodal) پشتیبانی کند. مدل‌های صرفاً متنی برای OCR مناسب نیستند.

## حریم خصوصی و انتشار کد

این مخزن فقط کد برنامه را نگه می‌دارد. موارد زیر عمداً با `.gitignore` منتشر نمی‌شوند:

- دیتابیس و تراکنش‌ها
- تصاویر فاکتور
- فایل‌های پشتیبان و لاگ‌ها
- `config.php` و کلیدهای API

هر نصب جدید، دیتابیس و تنظیمات خودش را ایجاد می‌کند. هرگز کلید API واقعی یا فایل `config.php` را در مخزن عمومی commit نکنید.

## ساختار پروژه

```text
├── index.html          # رابط اصلی کاربر
├── api.php             # API، احراز هویت، تراکنش‌ها و AI
├── db.php              # SQLite، مدل داده و نشست‌ها
├── admin.php           # پنل مدیریت
├── config.example.php  # الگوی تنظیمات بدون اطلاعات حساس
├── assets/             # فونت، آیکون‌ها و وابستگی‌های محلی
├── data/               # دیتابیس در زمان اجرا (در Git نادیده گرفته می‌شود)
├── uploads/            # رسیدهای آپلودشده (در Git نادیده گرفته می‌شود)
└── backups/            # پشتیبان‌های محلی (در Git نادیده گرفته می‌شود)
```
